# 琉璃TV 远程订阅源（移动 / 联通 / 全集备用）

本仓库把上游聚合直播源自动 **拉取 → 筛选 → 同名合并多线路 → 分类拆分**，
生成可直接填入 **琉璃TV** 的 M3U 订阅文件；星海验证清单与第三方直连源不单独成列表，
只作为已有频道的 **备用线路** 并入线路池。GitHub Actions **每 6 小时**
自动拉取一次上游，保持订阅内容最新。

### 备用线路

- 每台频道的第 1 条为内网主线路；第 2 条及以后统一写入最底部「其他·备用线路」分组，
  不占用中间分类位置；App 按频道名匹配 alternates，换线时依次切换；
- 每台备用线路最多保留 8 条，避免单台堆积过多死线。
- 联通内网同名存在标清（4:3）与高清双版本时，高清内网线置顶，标清线沉到内网末尾；
  仅有单一版本的频道保持原顺序，移动订阅不启用该规则。

### 台标说明

- 每个频道在 `#EXTINF` 行写入 `tvg-logo` 字段，台标统一取 fanmingming/live 台标库
  （`raw.githubusercontent.com/fanmingming/live/main/tv/`），不采信第三方源自带的死主机图标；
- 频道名经别名表 + 同系列/同省级台兜底匹配库内 PNG；库内确实没有台标的县市小台、人名电影台、
  轮播熊猫台不写图标，App 加载失败会回退空白、不崩溃；
- 台标库清单见 `seed/logos.txt`，别名与兜底规则写在 `scripts/build_sources.py`，
  定时重建时随订阅一起刷新。

### backup.txt（全集备用源）

上游除已收录分组外的其余分组原样收录（音乐 / DJ / 港台 / 轮播 / 地方台 /
咪咕央视 / 央视频2·3·5·6 等）；私密频道、JAV 點播、韩国团播等违规分组一律剔除；
rtsp / rtmp 等 App 不支持的协议、点播音视频文件、公众号推广地址自动过滤。

### 合并 / 过滤规则

1. **内网固定第一线路**：主线路分组频道排在订阅文件最前，播放优先走内网。
2. **同名频道合并多线路**：备用源里与主线路同名的频道，不重复列第二个频道卡片，
   备用地址并入该频道线路池；第 2 条及以后统一写入末尾「备用线路」分组。
3. **画质后缀归一**：`高清 / 超清 / HD / 4K / 8K / 1080P` 等后缀在合并与分类前剥离，
   同一台的不同线路不重复占卡片。
4. **整组剔除**：荔枝网、购物推广、私密 / 团播 / 点播等违规分组与关键词一律不收。

## 三、本地构建

```bash
# 联网拉取上游与第三方源
python3 scripts/build_sources.py

# 离线自测（用上一次保存的上游快照）
SOURCE_FILE=/path/to/upstream.txt python3 scripts/build_sources.py
```

产物输出到 `sources/`；配置项（上游地址、备用池源、剔除分组、线路上限、指定频道的优先线路）见 `config.json`。

### 指定频道优先线路

`subscriptions.<订阅>.line_priority` 按频道名指定优先线路（地址片段匹配，命中后顶到第一条）；
未命中规则的频道保持原顺序，联通订阅默认保留内网线路为首线。当前规则：

| 订阅 | 频道 | 优先线路 |
|---|---|---|
| 移动 | 广东珠江频道 | `xch819.cn` |
| 移动 | 大湾区卫视 | `20260809.xyz` |
